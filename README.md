# 🚀 Workshop API

A simple REST API platform created for an **API Testing Workshop**.

This project uses **JSON Server** to provide a RESTful API that students can test using **Postman** or a web browser.

---

## 🌐 API

The API provides sample resources such as:

- 👨‍🎓 Students
- 🛒 Products

The API supports standard CRUD operations:

- GET
- POST
- PUT
- PATCH
- DELETE
